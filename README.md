# The Workshop Box

A 108-card deck, presented as a single self-contained HTML page. Nine tabbed
sections, one colour each, in book order.

**Live:** https://feldtdesign-ship-it.github.io/workshop-box-deck/

## Files

- `index.html` — the whole deck. No build step, no dependencies. Open it in a browser.

Fonts (Archivo, Archivo Narrow, IBM Plex Mono) load from Google Fonts, so the page
needs a network connection to look right.
